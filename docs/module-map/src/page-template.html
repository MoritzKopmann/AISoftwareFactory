Reading notes

  • Use cases never import another module. A cross-module line runs from the use case to its own port, which main.ts fills with the other module's interface method. The dotted line then leads to the use case behind that method.
  • Watcher's subscriptions to project.added, run.finished and ticket.status-written update in-memory state and request a poll. Their lines end at PollRepositories.
  • RecoverInterruptedRuns emits run.finished itself and also through FinishRun.
  • tools (MCP) of bridge and findings are handed to LaunchRunSession. The agent session calls them, not the use case code.
  • skills.start runs both StartSkills and ReadCredentials. Only StartSkills is linked.
  • Left out: shared adapters (clock, bus, logger, identifiers), helper files without a class, routes, and GhCliGitHubToken, which only other infra uses. Watcher's RegisteredRepositories port calls projects.list from index.ts, not from a use case, so it has no line.
  • Snapshot of main at 9a40605, 2026-10-07. Domain boxes are a first proposal. Round 3: tickets #328–#331.
